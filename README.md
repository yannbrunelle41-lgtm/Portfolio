# Portfolio - Yann Brunelle

Je me forme au développement web et web mobile. Ce portfolio présente ma reconversion, mes compétences et les projets que je réalise pendant ma formation.

## Ouvrir le site en local

Télécharge ou clone le dépôt, puis ouvre [index.html](index.html) dans ton navigateur. Le site fonctionne directement avec les fichiers du dépôt, sans installation.

## Les pages

- [Accueil](index.html) - Présentation, téléchargement du CV, carrousel et contact
- [À propos](a-propos.html) - Parcours professionnel, formation et compétences
- [Mes projets](mes-projets.html) - Liste des réalisations
- [Insure](projet-1.html) - Intégration responsive d’une maquette Figma avec captures et bilan du projet
- [Mentions légales](mentions-legales.html) - Informations sur le site et la confidentialité

## Technologies utilisées

- HTML pour la structure des pages
- CSS pour la mise en page responsive et les effets de survol
- JavaScript pour le menu mobile et le carrousel
- Figma pour les maquettes

Les styles se trouvent dans [css/style.css](css/style.css) et le JavaScript dans [js/nav.js](js/nav.js).

## Formulaire de contact

Le formulaire est visible sur la page d’accueil. L’envoi des messages reste à mettre en place.
